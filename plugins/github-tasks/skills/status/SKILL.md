# Сводка по задачам

Только чтение: ни одной метки, комментария или коммита. Имена меток — из
`.claude/github-tasks.json` (поле `labels`), по умолчанию `ready`, `in-progress`,
`in-review`, `blocked`, `owner-decision`.

## Собери

- `gh issue list --state open --limit 200 --json number,title,labels,assignees` — открытые
  задачи с метками.
- `gh issue list --state closed --search "closed:>=<вчера>" --limit 200 --json number,title` —
  закрытые за сутки (у `gh` по умолчанию только 30; упёрлись в 200 — пиши «не меньше 200»).
- `gh pr list --state open --limit 200 --json number,title,headRefName,isDraft` — открытые PR.
- `git worktree list` — рабочие копии задач на этом диске.

## Сверь — расхождения

- `in-review`, а открытого PR из ветки `issue-N` нет;
- открытый PR из `issue-N`, а у задачи не `in-review` и не `in-progress`;
- `in-progress` без исполнителя или с исполнителем, но без метки;
- у задачи две метки статуса;
- рабочая копия `issue-N` на диске, а задача закрыта.

## Ответ — не больше 15 строк

Первой строкой — расхождения, если они есть. Дальше: в работе; на приёмке; ждёт решения
человека; блокеры (с причиной из последнего комментария, если она короткая); закрыто за
сутки; одно фактическое следующее действие. Само действие не начинай и дополнительной
работы не предлагай.

Задача в `in-progress`, в ветке которой давно нет коммитов, может принадлежать упавшей
сессии — отметь это как «возможно брошена, решает человек» (см. «Освобождение задачи» в
`${CLAUDE_PLUGIN_ROOT}/PROCESS.md`).
